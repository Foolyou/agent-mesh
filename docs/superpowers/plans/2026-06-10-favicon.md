# Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the approved Agent Mesh SVG favicon and wire it into the web console HTML.

**Architecture:** Keep the change at the static asset boundary. `index.html` declares browser metadata, `favicon.svg` contains the hand-authored mark, and a focused Bun test verifies the contract.

**Tech Stack:** Bun test runner, React client HTML entrypoint, SVG favicon asset.

---

## File Structure

- Create: `src/web/client/favicon.test.ts`
  - Verifies `index.html` links the SVG favicon and declares the dark theme color.
  - Verifies `favicon.svg` exists and contains the selected visual primitives.
- Create: `src/web/client/favicon.svg`
  - Hand-authored 32x32 SVG for the selected B direction.
- Modify: `src/web/client/index.html`
  - Adds favicon and theme-color metadata.

### Task 1: Favicon Contract Test

**Files:**
- Create: `src/web/client/favicon.test.ts`

- [ ] **Step 1: Write the failing test**

```ts
import { readFileSync } from "node:fs";
import { test, expect } from "bun:test";

const html = readFileSync(new URL("./index.html", import.meta.url), "utf8");

test("index html declares the agent-mesh favicon and theme color", () => {
  expect(html).toContain('<link rel="icon" type="image/svg+xml" href="./favicon.svg" />');
  expect(html).toContain('<meta name="theme-color" content="#0a0b0d" />');
});

test("favicon svg contains the approved mesh glyph mark", () => {
  const svg = readFileSync(new URL("./favicon.svg", import.meta.url), "utf8");

  expect(svg).toContain('viewBox="0 0 32 32"');
  expect(svg).toContain("#0a0b0d");
  expect(svg).toContain("#4ec97a");
  expect(svg).toContain('data-part="brand-block"');
  expect(svg).toContain('data-part="mesh-edge"');
  expect(svg).toContain('data-part="mesh-node"');
});
```

- [ ] **Step 2: Run test to verify it fails**

Run: `bun test src/web/client/favicon.test.ts`

Expected: FAIL because `index.html` has no favicon link and/or `favicon.svg` does not exist.
